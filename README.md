One line of software error copy that tells the brutal truth about what went wrong, entered in make.fun's "Say What Actually Broke" bounty: "We lost your data. Not all of it — just the part you needed. The rest is untouched, backed up twice, and frankly thriving."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the error message to `/tmp/out/entry.txt`.
